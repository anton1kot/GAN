# GAN — Генерация рукописных цифр

Нейросеть типа **GAN** (Generative Adversarial Network), которая учится генерировать рукописные цифры из набора данных MNIST.

## Как это работает

Две нейросети соревнуются друг с другом:

- **Генератор** — рисует цифры из случайного шума
- **Дискриминатор** — пытается отличить настоящие цифры от сгенерированных

На каждом шаге обучения сначала обучается дискриминатор, затем генератор учится его обманывать. Со временем генератор начинает создавать всё более реалистичные цифры.

## Требования

- Python 3.8+
- `tensorflow` (или `keras`)
- `numpy`
- `matplotlib`

Установка зависимостей:

```bash
pip install tensorflow numpy matplotlib
```

## Запуск

```bash
python "Цифры нейросеть.py"
```

При запуске появится подсказка с выбором количества эпох:

| Эпох | Примерное время | Результат |
|------|-----------------|-----------|
| 10   | 2–3 мин         | Цифры размытые |
| 20   | 4–6 мин         | Цифры узнаваемы |
| 50   | 10–15 мин       | Цифры чёткие |
| 100  | 20–30 мин       | Хорошее качество |

## Что увидишь

После каждой 5-й эпохи:

1. В терминале откроется окно с 16 сгенерированными цифрами (сетка 4×4)
2. В папке с файлом сохранится картинка `generated_epoch_N.png`
3. Закрой окно и нажми Enter, чтобы продолжить обучение

## Структура кода

| Функция | Назначение |
|---------|-----------|
| `load_data()` | Загрузка и нормализация MNIST |
| `create_generator()` | Создание генератора (3 скрытых слоя) |
| `create_discriminator()` | Создание дискриминатора (3 скрытых слоя + Dropout) |
| `create_gan()` | Объединение сетей в одну модель |
| `plot_generated_images()` | Визуализация результатов |
| `train()` | Основной цикл обучения |

## Технические детали

- **Архитектура:** 3 скрытых слоя в каждой сети
- **Функция активации:** LeakyReLU (скрытые), tanh (выход генератора), sigmoid (выход дискриминатора)
- **Оптимизатор:** Adam (lr=0.0002, beta_1=0.5)
- **Функция потерь:** binary_crossentropy
- **Batch size:** 128
- **Dropout:** 0.3 (в дискриминаторе)
- **Label smoothing:** 0.9 (вместо 1.0 для стабильности)
